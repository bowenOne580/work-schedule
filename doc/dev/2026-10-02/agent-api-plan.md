# Agent 任务规划接口

## 已确认范围

用户需要 agent 通过账号密码鉴权后创建和安排任务；安排只涉及优先级和截止日期，不新增日历时间段。保留原有网页操作和自动计时。

## 接口与鉴权

- API 基路径 `/api/agent/v1`；使用现有账号密码登录，返回一小时专用 Bearer Token。
- Agent Token 使用独立签名用途，不接受网页 Cookie，也不能作为网页会话访问系统接口。
- 登录失败按服务观察到的 IP 限制，15 分钟内失败 5 次后限流；不读取未经配置的转发 IP。
- 能力：读取上下文、查询任务、创建/修改任务、创建/修改检查点、读取/新建分类。禁止任务状态变更、计时字段、删除及系统管理。
- 严格校验字段，未知字段直接报错。优先级 1–5，P1 最高；截止日期为有效的 `YYYY-MM-DD`，可用 null 清除；估时可省略或为 null。

## 业务复用与一致性

- 独立 `AgentService` 在存储串行队列内组合 `SchedulerService` 的原有方法。内部存储适配器复用同一 draft，不再次进入存储队列；任务和嵌套检查点只在最外层提交。
- 新建支持 `Idempotency-Key`。请求指纹保存在所创建资源的 `_agentRequest` 字段，与资源一起原子替换文件，查询返回时不暴露该内部字段。键按账号、HTTP 方法和路径区分，有效期 24 小时；同键不同内容返回 409。
- 幂等记录依附资源：若资源被网页删除或从备份恢复丢失，无法保证该键的去重。重复请求返回当前资源，而非历史快照；部署保持现有单进程约束。
- PATCH 必须携带读取到的 `If-Match`，与规范化资源内容的 SHA-256 revision 比较；任务版本覆盖检查点，检查与写入在同一存储队列内进行。缺失返回 428，资源变化返回 412。避免仅用毫秒时间戳造成同一毫秒修改碰撞。
- 已完成任务不允许 agent 修改；所有实际用时和计时状态仍由服务器与网页任务操作管理。

## 文档与验证

- `doc/agent-api.md` 提供凭据配置、curl/Python 完整示例、权限、版本检查、幂等及错误处理说明。
- OpenAPI 输入 schema 与运行时校验共享定义；在线公开 `/api/agent/v1/openapi.json`，通过 `npm run agent:openapi` 生成可下载的 `doc/agent-api.openapi.json`。
- 使用临时存储、临时认证配置测试登录、Token 隔离/过期/篡改、失败限流、任务与检查点创建、优先级与截止日期、参数校验、重试和重载、并发版本冲突以及旧业务回归。
