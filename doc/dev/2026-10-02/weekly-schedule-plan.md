# 独立周日程表

面向学生录入每周固定占用和固定空闲，暂不与任务、推荐、计时或 Agent API 联动。按每周重复安排实现，每个条目可选多个星期，起止时间为 5 分钟整数倍。结束时间支持 24:00，跨午夜需要拆分条目；同一天的重叠安排返回明确提示，边界相接允许。

新增 `/app/schedule` 页面和导航，主体为周一至周日、纵向小时刻度的课表。蓝色表示占用、绿色表示空闲，同时显示类型文字和图例；未设置区域不推断为空闲。短时间段保持真实比例，完整名称与时间可通过下方条目列表查看和编辑。手机默认单日视图，可切换全周。

新增、编辑和删除使用居中弹窗，打开和关闭时保持课表尺寸与位置。弹窗支持 Escape、点击遮罩及取消关闭，保存期间禁止关闭；打开时聚焦名称，关闭后恢复触发控件焦点。星期为多选，时间下拉仅提供 5 分钟间隔。包含加载、失败重试及重叠提示。沿用现有应用外壳与字体；学生在白天的教室或图书馆查看课表，以浅色中性底和少量语义色保证可读性。按用户反馈删除副标题、空状态介绍、操作说明、表单补充说明、空白图例、周汇总和可见的成功提示；保留必要标签、实际时间数据、占用/空闲图例及错误信息，成功反馈仅向辅助技术播报。

数据独立保存在 `data/schedule_slots.json`，复用 JSON 存储队列、原子替换与备份恢复，由 `WeeklyScheduleService` 管理。现有任务导入导出不读写日程数据；日程备份位于 `data/backups/scheduleSlots/`。接口 `/api/schedule/slots` 的 GET/POST/PATCH/DELETE 使用已有网页 Cookie 鉴权，Agent Token 不开放该接口。

验证服务端时间边界与星期校验、相邻和重叠区间、并发写入、修改排除自身、重载与备份、任务数据隔离与鉴权；浏览器验证录入、可视化位置及颜色、重叠错误、编辑删除、刷新恢复、午夜边界、短时间段和手机布局。
