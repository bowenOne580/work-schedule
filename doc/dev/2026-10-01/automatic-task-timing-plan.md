# 任务自动计时与选填估时

## 需求

- 预计时间选填，缺省表示未估算。
- 开始和继续任务开启一轮计时，暂停保存本轮用时。
- 完成累计已保存用时与当前轮用时，不再手填实际时间。

## 实现

- 后端任务保存 `accumulatedMs`（已结束轮次累计毫秒）和 `timerStartedAt`（当前轮开始时间，未计时为 null）。串行存储队列保证并发状态切换只结算一次。
- 任务 `actualMinutes` 由累计毫秒派生，兼容统计接口；保留毫秒精度，避免多次短轮次分别取整造成用时丢失。
- 暂停、完成、推迟以及检查点触发自动完成时结算当前轮。检查点只管理完成状态和预计时间，不再覆盖任务实际用时。
- 前端显示实时累计用时，移除任务和检查点完成时的实际用时输入。
- 历史任务累计时间以已有实际用时初始化；历史进行中任务没有可靠的开始时间，从首次加载新逻辑时开始计时，不推断升级前的未记录时长。
- 浏览器刷新、关闭和服务重启保留进行中的计时起点，只有明确暂停、推迟或完成才停止计时。
- 未估时显示为“未估算”；检查点估时不完整时使用数量计算进度。

## 验证

- 使用可控时钟验证多轮累计、暂停间隔、最后一轮、短轮次、重载、重复请求、检查点自动完成及旧数据迁移。
- 验证 API 拒绝手填实际用时，选填估时可创建任务及检查点。
- 前端类型检查、构建与浏览器任务操作验证；测试使用隔离数据，不修改真实 data/。
